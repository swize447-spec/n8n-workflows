🤖 n8n Automation Workflows
A collection of AI-powered automation workflows built with n8n while learning how to connect APIs, language models, and everyday tools like Telegram, Discord, Gmail, and Google Sheets.
These workflows cover a range of real-world use cases — from chatbots and content generators to approval systems and video creation — all built without writing a full application from scratch.

What's inside

🤖 Telegram & Discord bots — AI assistants that respond to messages, generate content, and interact with users in real time
✅ Human-in-the-Loop workflows — approval systems where a human reviews and decides before anything gets sent or published
📰 Content generators — tools that write articles, tweets, and blog posts based on live web data
🎬 Video & image automation — workflows that generate images and short videos using Stable Diffusion and Shotstack
🔍 LinkedIn scraper — finds job posts and candidate profiles using AI-generated Boolean search strings
📊 Data & reporting — chart generation from Google Sheets data
🍽️ RAG-powered assistant — a restaurant chatbot that answers menu questions using uploaded documents and vector search


Tools & APIs used
n8n · OpenAI · Google Gemini · Telegram · Discord · Gmail · Google Sheets · Supabase · Stability AI · Pexels · Serper · Shotstack · X (Twitter) · SerpAPI · Cloudinary

Getting started
Each workflow has its own folder with:

a ready-to-import .json file
a README.md explaining how it works and how to set it up

Import any workflow into your n8n instance, add your credentials, and you're good to go.

Built as a learning project — always a work in progress. 🚀
